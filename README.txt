MARVELLOUS MINIS UK — SIMPLE UPDATE GUIDE

You only need to know TWO things.

1. CHANGE WORDS / CONTACT DETAILS
   Open: simple-edit.js

   The top of the file is clearly marked:
   "EDIT THIS FILE"

   Change the text between the quotation marks.

2. CHANGE PORTFOLIO PHOTOS
   Put your new photos in the images folder.
   Then edit the PORTFOLIO section in simple-edit.js.

   Example:
   { image: "images/my-mini.jpg", title: "My New Mini" }

SAVE AND UPLOAD
After making a change, save the file and upload/redeploy the website.

IMPORTANT
Keep a backup of the website ZIP before making big changes.
